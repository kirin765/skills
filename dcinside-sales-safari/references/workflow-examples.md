**시행착오**:
- `programming` 정식갤 → 잡담

**최종 선택**: `backend` 마갤 + `vibecoding` 마갤

### 거대 갤 처리 (backend 32,449건)

기본 필터 통과: 9,989건 (~4시간 detail) → 너무 많음

→ 필터 강화:
| 기준 | 통과 건수 |
|---|---|
| comment≥6 OR recommend≥2 | 9,989 |
| comment≥10 OR recommend≥3 | 4,526 |
| **comment≥15 OR recommend≥5** | **1,959** ★ 채택 |
| comment≥30 OR recommend≥7 | 750 |

`fetch_detail.py --min-comments 15 --min-recommend 5`로 30분 내 완료.

## 거대 갤 vs 죽은 갤 처리 매뉴얼

### 거대 갤 (12개월 10,000건+)

```bash
# 기본 필터 통과율 먼저 확인
python3 -c "
import json
total=pf=0
with open('raw/{GALL}_meta.jsonl') as f:
    for line in f:
        d=json.loads(line); total+=1
        if d['comment_count']>=6 or d['recommend']>=2: pf+=1
print(f'{total} total, {pf} pass ({100*pf/total:.0f}%)')
"

# 통과 5,000+ 이면 필터 강화
python3 fetch_detail.py --gall {GALL} --min-comments 15 --min-recommend 5
```

### 죽은 갤 (12개월 100건 미만)

```bash
# 메타 스캔이 빈 페이지에서 무한 루프 도는 경우
pkill -f "fetch_meta.py --gall {GALL}"
```

데이터가 너무 적으면(필터 통과 <10건) 단일 신호 노트로 분리 또는 제외.

### 페르소나 불일치 의심 시 빠른 검증

```bash
# 첫 30건 샘플로 페르소나 빠르게 확인
head -30 raw/{GALL}_meta.jsonl | python3 -c "
import sys, json
for line in sys.stdin:
    d = json.loads(line)
    print(f'  - {d[\"title\"][:60]}')
"
```

샘플 30건 중 절반 이상이 페르소나에 맞지 않으면 **즉시 제외**. 3시간짜리 detail fetch 돌리지 말 것.

## 클러스터 자격 기준 (4-체크박스)

새 클러스터 작성 전 다음 모두 만족:

- [ ] **3명 이상 고유 인원** 동일 고통 표현 (uid+ip dedup 후)
- [ ] 기존 부분 해결책 존재 (완전 미해결 = 시장이 너무 이름)
- [ ] 갭이 구체적·빌드 가능 (모호한 "더 좋아야" 아님)
- [ ] 반복적·지속적 고통 (일회성 이벤트 아님)

3명 미만이면 단일 신호 노트로 분리. 4/4 미통과 시 추가 조사.
