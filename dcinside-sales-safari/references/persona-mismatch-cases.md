# 페르소나 불일치 사례 — 학습된 함정 카탈로그

dcinside 갤 ID는 영어 단어를 그대로 쓰는 경우가 많아서 **이름만 보고 페르소나를 가정하면 안 된다**. 2026-05 Sales Safari 작업에서 실제 빠진 사례들. 같은 함정 반복하지 말 것.

---

## 페르소나 검증의 절대 원칙

> 12개월 메타 스캔 시작 **전에**, 반드시 page1 샘플 제목 5~10개를 사람이 직접 확인한다.
> 키워드 검색만으로 페르소나를 가정하면 17만건 짜리 갤을 헛스캔하고 시간 낭비.

`probe_galleries.py` 출력의 샘플 제목을 보고 다음을 판정:
1. 제목 화자가 우리가 찾는 페르소나(예: 사장·강사·셀러)인가?
2. 일반 소비자/팬덤/잡담/정치인가? → 제외
3. 학생 페르소나인가 vs 운영자 페르소나인가? → 명확히 구분
4. 갤 제목(`<title>`)이 의도한 도메인과 맞는가?

## 실제 함정 사례

### `coffee` (마이너 갤러리, 16.7만건/12개월)

- **기대**: 카페 사장 페르소나
- **실제**: 일반 커피 마니아·홈카페 동호회
- **샘플 제목**: "심비오시스 취소할까", "리버스 에쏘머신이라니", "손위에서 칼썰지마라", "캠핑믕"
- **교훈**: 영어 단어 = 그 단어를 좋아하는 마니아 갤일 가능성이 높음. 사업자 페르소나는 한국어 직군명이 더 잘 잡힘.

### `academy` (마이너 갤러리, 4,357건)

- **기대**: 학원 운영 페르소나
- **실제**: **사관학교 입시** (육사·해사·공사) 학생/학부모
- **샘플 제목**: "군위탁 의대", "사관학교 입시", "공사 지망생", "셤 6일 전"
- **교훈**: "academy"는 영어로 military academy. 한국 학원 페르소나는 `instructors` 또는 `ptutor`.

### `youtube` (마이너 갤러리, 7,333건)

- **기대**: 유튜버 크리에이터
- **실제**: 시청자 + 정치/혐오 글
- **샘플 제목**: "유튜브 알고리즘 ㅈ노잼", "유튜브 양키넘들 양아치", "프리미엄 호구임?"
- **교훈**: 플랫폼 이름 갤은 시청자 위주. 크리에이터는 dcinside 본진이 아님 (X·네이버 카페가 적합).

### `creator` (마이너 갤러리)

- **기대**: 크리에이터 본인 페르소나
- **실제**: 일반 시사·짤방·잡담 ("백종원", "이재명 공약", "포켓몬", "장원영")
- **교훈**: 일반 명사 갤은 잡담 하위문화 갤로 변질된 경우가 많음. 직군 한정 키워드(예: `instructors`)가 안전.

### `programming`, `outsourcing`, `rust`, `indiegame`

- **기대**: 개발자/외주/게임 빌더 페르소나
- **실제**: 잡담 위주, 페르소나 검증 실패
- **교훈**: dcinside 정식갤(board)은 마갤보다 잡담이 많은 경향. 직군 마갤(예: `backend`)이 페르소나 더 명확.

### `bar`, `gogi`, `designer`, `fitness`

- **기대**: 술집/고깃집 사장, 디자이너, 헬스장 사장
- **실제**: 게임/만화 갤(`bar`=비욘드 올 리즌, `gogi`=고기서 만나), 건축설계갤, 피트니스 동호회
- **교훈**: 갤 `<title>` 항상 확인. 영어/한자 짧은 단어는 다른 의미로 selpyte된 경우 多.

### `beauty`, `selfemployed` (둘 다 마이너 갤러리)

- **기대**: 미용실 / 자영업 일반 페르소나
- **실제**: 페르소나는 맞지만 **갤 자체가 너무 작음** (12개월 154건 / 135건)
- **필터 통과**: 4건, 3건 — 분석 불가
- **교훈**: 페르소나 맞아도 engagement 낮으면 클러스터 신호 못 만듦. 최소 page1 row 30+ 권장.

## 거대 갤 처리 (10,000건+)

거대 갤은 12개월 메타 스캔이 가능하더라도 **detail fetch가 비현실적**:
- 9,989건 detail = 1.5초/건 = 4시간

대안:
1. **필터 임계값 강화**: `comment_count >= 15 OR recommend >= 5` (sajang의 9,989 → 1,959)
2. **샘플링**: 필터 통과 후 무작위 1,500건 선택
3. **시기 한정**: 최근 6개월만

backend 갤(32,449건) → 1,959건 필터 → ~30분 detail = 적정.

## 죽은 갤 / 무한 루프 버그

`fetch_meta.py`에서 `selfemployed` 갤이 16,000+ page까지 빈 페이지 도는 사례 발견. 원인:
- 페이지에 row가 있지만 모두 12개월 컷오프 통과한 글이 아니라서 새로 yield되지 않음
- 종료 조건은 "old_in_page >= len(rows) // 2 AND old_in_page > 0" → 모두 dedup된 상태면 트리거 안 됨

대응:
- 백그라운드 실행 시 page 카운트 모니터링 (10000+면 의심)
- `--max-pages` 옵션으로 안전판 추가 가능 (기본 미설정)
- 필요 시 `pkill -f "fetch_meta.py --gall {ID}"` 으로 강제 종료

## 정치·혐오 노이즈 일반론

dcinside는 정치·혐오 글이 어느 갤에든 일정 비율 끼어 있다. vocab의 emotion_high 단어가 정치 글에 잡힐 가능성:
- "좆같다", "씹새끼", "미친" 등 → 정치 토론에서도 나옴
- 추정 노이즈 비율: Tier 1 (score≥6)의 5~10%
- 클러스터링 시 명백한 정치 글은 단일 신호 노트로 분리하거나 제외
