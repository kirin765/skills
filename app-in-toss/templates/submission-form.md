# 앱인토스 제출 폼 데이터 템플릿

콘솔 앱 정보와 (해당 시) 챌린지 신청폼에 넣을 데이터를 프로젝트에서 뽑아 채운다. `appName`은 콘솔과 **정확히 일치**해야 한다 — 챌린지 신청폼은 자동 대조된다.

## 0. 식별자 (변경 불가 — 등록 전에 확정)

| 필드 | 값 | 규칙 |
|---|---|---|
| appName | (예: `neon-switch`) | `intoss://` 스킴 ID. 영문·소문자·하이픈. 등록 후 변경 불가, 인증서 발급 실패 유발 가능 |
| 앱 유형 | 게임 / 비게임 | 이후 폼 항목이 달라짐 |
| 프로젝트 root | (절대 경로) | `.ait` 빌드 위치 |
| 스토어링크(게임) | (플레이/앱스토어 페이지 URL) | 등급분류 경로 1: 오픈마켓 출시작일 때 필수 |

## 1. 앱 정보 (콘솔 → 앱 정보 → 수정하기)

### 기본 정보
| 필드 | 값 | 작성 가이드 |
|---|---|---|
| 한글 앱 이름 | | 토스 앱 노출명 |
| 영문명 | | 15자 이내 · 발음 쉬운 명사형 · 명령문/동사구 금지 · 일반 단어 단독 금지 |
| 부제 | | 검색 결과 노출. 비속어·느낌표 금지 |
| 상세 설명 | | '서비스 접속 → 행동 → 결과' 흐름으로 구체적으로. 홈 광고 대상 선정 근거가 됨 |
| 고객문의 이메일 | | 필수 |

| 등급분류번호 | | 조회값과 동일 (예: GOOG-SG-... ) |
| 이용등급 | | 조회값과 동일 |
| 내용정보 | | 전체이용가라도 있으면 선택 |

| 플레이 화면 | 마켓 출시작 2장 + 앱인토스 출품작 2장 | 원본 그대로, 편집 금지 |

## 2. 수익화 데이터 (콘솔 등록 전 수집)
| 항목 | 값 |
|---|---|
| IAP SKU 목록 | `heart_5` (하트 50개) 등 — 소모품/비소모품 구분, 상품명·이미지 1024²·공급가(400~1,400,000원, 10원 단위) |
| 광고 그룹 이름·유형 | `게임종료_전면`(전면) · `리바이브_리워드`(리워드, 보상: 부활 1회) · `홈_배너`(배너) |
| 광고 그룹 ID 3종 | 전면 `ait.v2.live.<hex>` · 리워드 `...` · 배너 `...` — 콘솔 상세 화면에서 발급(최대 2시간 후 구글 등록). dev/live 전환은 env(`VITE_*_AD_GROUP_ID`)로 |
| 프로모션 코드(env) | `VITE_PROMOTION_CODE` — .env.local에만, git 미추적 |
| 미션 정의 | 예: 점수 10점 달성 시 토스포인트 500 |

## 3. 챌린지 신청폼 (바이브코딩 챌린지 참가 시)

| 필드 | 값 | 주의 |
|---|---|---|
| 한국어 앱 이름 | | 콘솔 앱 이름과 동일 권장 |
| appName | | **콘솔 입력과 정확히 일치** — 불일치 시 출품 무효 |
| 설명(한줄 소개) | | 출품 적합성 판단 기준 |
| 챌린지 주제와의 연관성 | | 테마 가이드(예: "하찮아도 괜찮아")에 대응하는 한 문단 |
| 번들 등록 기한 | | 콘솔에서 .ait 버전 등록 — 마감(예: 08-26) 전 필수. 앱 정보 미승인 상태여도 버전 등록 가능 |
| 자격 제약 | | 챌린지 시작일 이전 출시 미니앱 출품 불가 · 1인 복수 출품 시 상금은 최우수 1개만 |

## 4. 검토 전 자체 점검 (게임 기준)
- [ ] 10초 이내 최초 화면 · 사운드 On/Off · 백그라운드 시 사운드 종료
- [ ] 닫기 버튼 · Safe Area 침범 없음 · 진입 즉시 바텀시트 없음
- [ ] 인앱 광고가 인트로/로딩/컷신/팝업에 없음 · 광고 사전 로드 · 배너는 상하단만
- [ ] IAP: 결제 중 음악 일시정지 · 주문금액=결제창 금액 · 취소/실패 사유 노출
- [ ] evaluator 금지(eval) · https/wss만 · 민감정보 DB 암호화
- [ ] 광고 테스트는 테스트용 ID만 사용 — 운영 ID로 테스트하면 제재
