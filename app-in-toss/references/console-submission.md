# 콘솔 — 등록 · 앱 정보 · 등급분류 · 검토/출시 절차

앱인토스 공식 문서(developers-apps-in-toss.toss.im) 실측 요약. 세부는 항상 공식 문서를 1차로 확인한다.
관련 문서: [콘솔/미니앱 등록](https://developers-apps-in-toss.toss.im/guide/operation/console-workspace.md) · [출시](https://developers-apps-in-toss.toss.im/guide/operation/deploy.md) · [테스트](https://developers-apps-in-toss.toss.im/guide/operation/toss.md) · [사업자 등록](https://developers-apps-in-toss.toss.im/guide/operation/register-business.md) · [게임 출시 가이드](https://developers-apps-in-toss.toss.im/checklist/app-game.md)

## 1. 가입 · 워크스페이스

- 콘솔: https://apps-in-toss.toss.im — 가입은 **토스 비즈니스 회원** 기준. 조건: 만 19세 이상 + 본인 명의로 로그인된 토스 앱.
- 워크스페이스는 **사업자당 1개**만. 이름 중복 불가(나중에 변경 가능).
- 권한: 대표관리자(서비스 약관 동의·관리자만 신청 가능) / 관리자(전체 관리+정산) / 구성원(권한 받은 앱만).

## 2. 앱 등록 (최소 입력 3개 — 나머지는 나중에)

- **앱 이름** — 토스 앱 노출명. 영문명 규칙: 15자 이내 · 발음 쉬운 명사형 · 명령문/동사구 금지('Book a Taxi' ✗ → 'GoRide Taxi' ○) · 뜻이 다른 일반 단어 단독 금지 · 3단어 이상/어려운 복합어 금지.
- **appName** — `intoss://` 스킴의 ID. **등록 후 변경 불가**. 규칙 위반 시 서버 인증서 발급 실패 가능.
- **앱 유형** — 게임 / 비게임. 이후 입력 항목이 달라진다.

개발 앱과 라이브 앱을 나눠 등록할 수 있다(테스트용·실배포용 별도).

## 3. 앱 정보 입력 (출시 전 필수, 검토 후 출시)

검토 요청해야 출시 가능. 항목은 임시 저장 가능.

### 3-1 기본 정보
- **부제** — 검색 결과에서 이름 아래 노출. 비속어·느낌표 금지.
- **상세 설명** — 토스 홈 광고 대상 선정 근거가 됨. '서비스 접속 → 행동 → 결과' 흐름으로 구체적으로(예: "우산을 잡고 내려오는 적들 / 번개·화살·주먹 무기 / 2턴마다 무기 선택 / 몬스터 10번 처치 시 골드 20개").
- **사용 연령** — 현재 앱인토스는 만 19세 이상 사용자만 제공.
- **고객문의 이메일** — 필수.

### 3-2 카테고리 및 노출
- **카테고리** — 게임: 장르 선택 + **웹보드 여부 체크**(웹보드면 성인인증·고객센터·확률형 아이템 고지 의무). 비게임: 대분류→중분류→소분류(같은 중분류 중복 선택 불가). 실제 서비스와 다르면 검토에서 강제 교체됨.
- **앱 로고** — 600×600 PNG·정사각. **배경색 필수(투명 배경·둥근 모서리 금지)**. 다크 모드 대응. 토스 제공 리소스 사용 금지.
- **썸네일(게임)** — 1932×828 PNG. 핵심 플레이 화면. 빈 공간을 색·블러로 채우지 않기.
- **스크린샷(선택)** — 세로 636×1048 최소 3장 / 가로 1504×741 최소 1장. 제출하면 검색·미리보기에 선반영.
- **리더보드(게임)** — 점수 단위·정렬 정책 설정.

### 3-3 게임 등급분류 (게임 필수, 증빙 제출)
두 경로 중 하나:
1. **오픈마켓 출시 심사 완료** → 스토어 URL + **자체등급분류 게임물 정보**:
   - 등록자명(Play=개발자명 / AppStore=제공자명) · 자체등급분류사업자명(구글·애플·원스토어 등) · 등급분류일자 · **등급분류번호** · 이용등급 · 내용정보(전체이용가라도 있으면 선택) · **대표자 인감/사인 이미지** · 플레이 화면(마켓 출시작 2장 + 앱인토스 출시작 2장, 원본 그대로)
   - 게임물관리위원회 '자체등급분류 게임물 조회'에서 조회한 값과 일치해야 함. **등록자명≠사업자명이면 검수 반려**(개인: 사유 제출, 사업자: 등기부등본 소명).
2. **게임물관리위원회 심의 완료** → '게임물 등급분류증명서' PDF 첨부 + 증명서와 동일하게 입력.

## 4. 검토 · 출시 · 운영

- **앱 정보 검토**: 요청 후 영업일 1~2일. 콘솔+이메일 안내.
- **버전 검토**: 테스트 최소 1회 완료 후 '검토 요청하기' 활성화. 최대 3영업일(카테고리에 따라 7일+). **한 번에 한 버전**만 제출. 버그 발견 시 '요청 취소하기' → 새 번들 업로드 → 재요청.
- **출시하기** — 전체 사용자 즉시 반영. 롤백 가능(앱 출시 메뉴에서 이전 버전 선택→출시). **핫픽스**: 실행 불가 수준 오류는 채널톡 문의.
- **사후 검수** 존재 — 출시 후에도 개선 요청 가능, 법·정책 위반 시 긴급 운영 중단.
- **모니터링**: 로그/크래시(Sentry) · API 지연·실패율 · 사용자 신고 내역(콘솔 '신고 내역').

## 5. 번들(.ait) 업로드 제약

- 압축 해제 기준 **100MB 이하**. 대용량 리소스는 외부 스토리지/CDN + Lazy Loading(번들 안에 넣지 말 것).
- 콘솔 업로드 또는 CI/CD: `npx ait deploy --api-key {API 키}` / `npx ait token add` 후 `npx ait deploy [-m "메모"]`. 옵션: `--timeout`(10~300초).
- 업로드할 때마다 새 `deploymentId` 발급. 테스트 스킴: `intoss-private://appsintoss?_deploymentId={id}` (+ path·queryParams URL 인코딩).

## 6. 외부 통신(CORS) 주의

- SDK 3.x: 실서비스 `https://<appName>.web.tossmini.com` · QR 테스트 `https://<appName>.private-web.tossmini.com`. SDK 1~2.x: `apps.tossmini.com` / `private-apps.tossmini.com`.
- **2026-08-25 안내**: 그 이후 업로드되는 SDK 3.x 번들도 2.x Origin(`apps.tossmini.com`)으로 서비스된다고 공지 — 배포 시점 공식 문서에서 재확인.
- 샌드박스는 http 허용, **라이브는 https만**. iOS 서드파티 쿠키 차단 → 토큰 기반 인증.
- iframe 금지(보안 심사 반려; YouTube 영상 삽입만 예외). SSR 금지(CSR/SSG만).

## 7. 출시 가이드 핵심 체크리스트(게임)

- 10초 이내 최초 화면 · 사운드 On/Off 제공 + 백그라운드 전환 시 즉시 종료
- 닫기 버튼 노출 · Safe Area(다이내믹 아일랜드) 미침범 · 진입 즉시 바텀시트 금지 · 모든 화면에서 나갈 방법
- **인앱 광고를 인트로/로딩/컷신/팝업 모달에 노출 금지** · 광고는 사전 로드 · 배너는 상단 또는 하단에만
- 결제 중 음악 일시정지 · 주문금액=결제창 금액 일치 · 기기 변경에도 결제 데이터 유지
- eval 금지 · `window.location.replace` 류 금지 · wss/https만
