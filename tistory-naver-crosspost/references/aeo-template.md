# AEO 글쓰기 템플릿 — kirin765 티스토리 + 네이버 블로그

AEO는 AI 답변 엔진(ChatGPT 검색·Perplexity·구글 AI 개요·네이버 Cue:)이 글을 **인용하기 좋게** 만드는 최적화다.
답변 엔진은 글 전체를 읽지 않는다. 자기완결적인 조각(직답 문단·FAQ·표·단계)을 뽑아 쓴다.
규칙은 하나다. **각 조각이 앞뒤 없이 혼자 읽혀도 답이 되게 쓴다.**

## 먼저 알아야 할 사실 두 가지 (실측으로 확인함)

1. **핵심 레버는 스키마가 아니라 본문 구조다.** 구글은 2023년에 FAQ·HowTo 리치결과를 대부분 사이트에서 폐지했다. JSON-LD 스키마의 AEO 효과는 지금 미미하다. 답변 엔진은 눈에 보이는 텍스트 구조를 읽는다.
2. **티스토리 본문에는 JSON-LD를 못 넣는다.** 에디터(TinyMCE)가 저장 시 `<script>`를 제거한다. 네이버 스마트에디터도 마찬가지다. 스키마가 정 필요하면 스킨 레벨에서만 가능하다. 우선순위 낮음.

**결론: 아래 본문 구조 규칙만 지키면 된다. 티스토리·네이버 공통이다.**

---

## 글 골격 (위→아래 순서)

### 1. 답 먼저 블록 — 맨 처음 (필수)
제목이 던지는 질문에 대한 직답을 40~80자로 맨 앞에 둔다. 굵게(`<b>`) 처리한다. 훅은 그다음 문단.
- 나쁨: "본격적인 삼복더위가 시작됐습니다…" (훅 먼저 = 엔진이 뽑을 답이 없음)
- 좋음: "**2026년 중복은 7월 25일 토요일, 말복은 8월 14일 금요일입니다.**" ← 이 한 문단이 그대로 인용된다.

### 2. 질문형 소제목 (H2)
모든 소제목을 사용자가 검색창에 칠 질문으로 쓴다. 라벨 금지.

| 라벨 (금지) | 질문형 (사용) |
|---|---|
| 커리큘럼 | 어떤 순서로 배우나요? |
| 다운로드 | 어디서 받나요? |
| 복날 음식 추천 7가지 | 복날에 뭘 먹으면 좋나요? |
| 삼계탕 끓이는 법 | 집에서 삼계탕은 어떻게 끓이나요? |

### 3. 사실은 표·리스트로
비교·순위·수치·날짜는 표. 절차는 번호 리스트(`<ol>`). 답변 엔진은 문단보다 표·리스트를 먼저 뽑는다.

### 4. 엔티티 명확화
앱·제품·용어는 첫 등장에서 정의한다. "이 앱"이 아니라 "'모스부호 배우기'(안드로이드 앱)".

### 5. 자주 묻는 질문 섹션 — 맨 끝 (필수)
실제 검색되는 질문 3~6개를 Q&A로 단다. 답은 각 1~3문장, 자기완결. **눈에 보이는 텍스트로 쓴다** (스키마 아님).
형식: `<p><b>질문?</b><br>답변.</p>`

### 6. 이미지 alt
모든 이미지에 내용 설명 alt. "img_01" 금지, "복날 삼계탕 한 상 차림"처럼.

---

## 발행 전 체크리스트
- [ ] 첫 문단이 제목 질문에 직답 (40~80자, `<b>`)
- [ ] 소제목 전부 질문형
- [ ] 비교·수치·날짜가 표에, 절차가 `<ol>`에
- [ ] 앱/용어를 첫 등장에서 정의
- [ ] 자주 묻는 질문 3개 이상 (보이는 텍스트)
- [ ] 이미지 alt 전부

## 네이버 블로그 추가 규칙
네이버는 위 본문 구조를 그대로 쓰되, 다음이 다르다.
- **JSON-LD 불가** (스마트에디터가 제거). 본문 구조만으로 승부.
- **키워드는 제목·본문 첫 문단·태그에 반드시 반복.** 네이버 검색은 C-Rank·D.I.A. 기반이라 키워드 명시성과 체류시간이 중요.
- **태그 10개**를 질문·동의어 위주로 (예: "2026중복", "말복날짜", "복날음식", "삼계탕끓이는법").
- 본문은 크로스포스트 스킬이 `keyboard.type`으로 한 줄씩 넣는다. 표는 네이버 표 도구로 별도 삽입 필요(HTML 표가 그대로 안 넘어감).

## 티스토리 기존 글 주입 방법 (검증됨)
편집기에서 `window.tinymce.activeEditor`로 조작한다. CodeMirror·textarea 직접 수정은 저장 안 됨.
```js
const ed = window.tinymce.activeEditor;
ed.setContent(html);   // 이미지 매크로 [##_Image|...##] 와 data-ke-size 속성 보존할 것
ed.setDirty(true);
ed.fire('change');
ed.save();             // ← 이게 없으면 발행 시 원본이 저장된다 (핵심)
```
이후 `#publish-layer-btn` → `#publish-btn`(공개 발행) 클릭. `/manage/posts`로 리다이렉트되면 저장 성공.
