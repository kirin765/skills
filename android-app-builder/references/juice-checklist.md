# "Juice" 품질 체크리스트

밋밋한 프로토타입과 "퀄리티 최상"을 가르는 것들. 각 항목은 `assets/`의 어디에 구현돼 있는지 표시. 새 게임에선 장르에 맞게 취사선택.

## 그래픽
- [ ] **그라데이션 하늘 + 햇살 글로우** — 단색 배경 금지. `textures.ts`의 `sky`/`sun`(`softCircle`로 가짜 radial).
- [ ] **패럴랙스 3겹+** — 먼 언덕 / 가까운 언덕(TileSprite, `tilePositionX`) + 독립적으로 흐르는 구름. 바닥은 파이프 속도로 스크롤.
- [ ] **캐릭터 디테일** — 눈·부리·날개. 날갯짓은 3프레임 텍스처 + `anims`(yoyo). `drawBird(g, wingY)`.
- [ ] **속도 기반 기울기** — `bird.angle`을 `velocity.y`에 비례시켜 `Linear`로 부드럽게 lerp.
- [ ] **입체 셰이딩** — 장애물에 하이라이트 stripe + 그림자 edge + 캡. 평면 사각형 금지.
- [ ] **파티클** — 점프 먼지(`puff`), 점수 반짝임(`spark`, ADD 블렌드), 충돌 파편 + 깃털(중력). `buildEmitters()`.

## 사운드 (`audio.ts` — 게임 무관, 그대로 복사)
- [ ] **절차적 SFX** — 에셋 파일 0개. Web Audio로 합성. 점프/점수/마일스톤/충돌/스워시/버튼.
- [ ] **점수음 음정 상승** — 콤보가 쌓일수록 pitch ↑(`playScore(combo)`)로 streak 손맛.
- [ ] **음소거 토글** — localStorage 저장 + 벡터 스피커 아이콘 버튼. 첫 탭에서 `resumeAudio()`(브라우저 오디오 정책).

## UI/UX
- [ ] **애니메이션 시작 화면** — 타이틀 부유, 힌트 펄스(alpha yoyo), 새 bob 트윈.
- [ ] **점수 팝** — 증가 시 scale 1→1.35→1 yoyo.
- [ ] **마일스톤 축하** — 10점마다 화면 플래시 + 플로팅 텍스트 + 큰 반짝임 + 아르페지오.
- [ ] **게임오버 패널** — 둥근 패널(그림자+테두리), GAME OVER, 점수/최고, 재시작 버튼. `Back.out`으로 등장.
- [ ] **카메라 연출** — 사망 시 `shake` + `flash`. 재시작 시 `fadeOut`→`scene.restart()`.

## 점수 / 메타
- [ ] **최고 기록 영구 저장** — localStorage. 시작 화면·패널에 표시.
- [ ] **메달 등급** — 점수 구간별 브론즈/실버/골드/플래티넘 텍스처. 신기록 시 NEW! 배지.
- [ ] **난이도 상승 곡선** — 점수에 따라 갭↓·속도↑·생성주기↓. `get gap()/pipeSpeed()/spawnDelay()` 게터로 표현해 한 곳에서 튜닝.

## 상태 관리
- [ ] **명시적 상태머신** — `'ready' | 'playing' | 'dead'`. 입력·업데이트·스폰을 상태로 분기. 불리언 플래그 난립 금지.
- [ ] **재시작 잠금** — 사망 직후 600ms는 재시작 입력 무시(패널 보기 전 오발 방지).
