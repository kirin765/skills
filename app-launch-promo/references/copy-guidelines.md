# 플랫폼별 카피 가이드

같은 홍보라도 플랫폼마다 문화가 다르다. 한 글을 5곳에 복붙하면 어디서는 길이가 잘리고 어디서는
해시태그가 과하다. 1차 언어는 한국어. 모든 카피 끝에 CTA 링크를 넣되, **플랫폼마다 어떤 링크가 필수인지 다르다**:

| 플랫폼 | 필수 링크 |
|---|---|
| Instagram · Threads · TikTok | **Play Store 링크** (CTA) |
| X | **YouTube 홍보영상 watch URL** (필수) + 스토어 링크(선택) |
| YouTube · disquiet · inpock | 스토어/랜딩 URL |

X의 YouTube 링크는 YouTube 업로드가 끝나야 생기므로 **업로드 후 주입**한다(워크플로우상 YouTube가 X보다 먼저).
Play Store 링크는 카피에 들어가기 전에 **유효성(실제 등록정보가 뜨는지) 사전검증**을 통과해야 한다(SKILL.md 0단계).

공통 재료(0단계 입력에서):
- 한 줄 훅 = 첫 줄에 둔다. 스크롤 멈추게 하는 한 문장.
- 핵심 기능 2~3개를 짧게.
- CTA + 링크.

## Instagram (Reels 캡션)
- 길이: 캡션 ~2,200자 가능하지만 **앞 125자가 더보기 전에 보임** → 훅을 맨 앞에.
- 해시태그: 5~10개, 캡션 맨 끝에 묶어서. 앱 카테고리 + 한글 태그 섞기 (#앱추천 #안드로이드앱 등).
- 톤: 캐주얼·이모지 OK.
- **링크: 캡션 CTA에 Play Store 링크 필수.**

## Threads
- 길이: 500자 제한. 짧고 대화체. 해시태그는 1~3개만(스레드는 태그 문화 약함).
- 톤: 메이커가 직접 말하듯. "방금 ~~ 출시했어요" 느낌.
- **링크: 본문에 Play Store 링크 직접 포함(필수).**

## X (Twitter)
- 길이: 280자(기본). 훅 + 링크 + 해시태그 2~3개로 압축. 길게 쓸 거면 스레드로 쪼갠다.
- 톤: build-in-public 톤. 영어 병기하면 도달 ↑(선택).
- **링크: 끝에 YouTube 홍보영상 watch URL을 반드시 포함**(YouTube 업로드 후 주입 — X의 선행 단계가 YouTube다).
  스토어 링크는 선택. 280자에 YT 링크가 우선이며, 자리가 모자라면 스토어 링크를 빼고 YT 링크를 남긴다.
  영상 파일은 본문에 첨부(첨부 영상 ≠ YT 링크, 둘 다 들어간다).

## TikTok (영상 설명)
- 길이: 설명 ~2,200자지만 짧게. 해시태그가 발견의 핵심 → #fyp 류 + 앱/카테고리 태그 5~8개.
- 톤: 트렌디·후킹. 첫 문장이 곧 후크.
- **링크: 설명에 Play Store 링크 필수.**

## YouTube (제목/설명/태그)
- 제목: ≤100자, 검색 키워드 포함. `<`, `>` 문자 금지.
- 설명: ≤5,000자. 첫 2~3줄에 핵심 + 링크(접힘 전 노출). 그 아래 기능 목록.
- 태그: 쉼표 구분, 앱 이름·카테고리·기능 키워드.
- 세로영상만 있으면 Shorts(제목에 #Shorts 권장은 선택).

## disquiet (메이커 로그)
- 톤: 한국 인디메이커 커뮤니티. 출시 소식 + 무엇을·왜 만들었는지 + 기능 + 링크.
- 길이: 2~5문장이면 충분. 과한 마케팅 톤보다 메이커 회고체가 잘 맞는다.
