# inpock 링크 추가 플레이북 (Claude in Chrome)

계정: happylife2080@gmail.com. 인포크링크(link.inpock.co.kr)는 인디메이커 채널을 묶는 링크허브다.
신규 앱 링크를 하나 추가하는 게 목표.

1. **계정 확인** — `navigate` link.inpock.co.kr/admin → 로그인 계정이 happylife2080인지 확인.
   로그아웃/불일치면 건너뛰고 리포트에 기록(자동 로그인 X).
2. **링크 추가 진입** — 어드민에서 "링크 추가 / + 버튼"을 찾는다(`find`/`get_page_text`로 현재 UI 확인).
3. **링크 정보 입력**:
   - 제목/라벨 = 앱 이름
   - URL = 스토어/랜딩 URL (0단계 입력)
   - 썸네일/아이콘 옵션이 있으면 앱 아이콘 사용(있을 때만; 파일 업로드 막히면 건너뜀).
4. **저장** — 저장/추가 버튼.
5. **확인** — 링크 목록에 새 항목이 보이는지, 공개 링크허브 페이지에 노출되는지 확인.

inpock UI는 변할 수 있으니 셀렉터는 화면을 보고 적응한다. 순서·필드명이 달라도 "새 링크 항목을
만들어 앱 이름 + URL을 넣고 저장"이 본질이다.
