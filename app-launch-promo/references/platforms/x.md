# X (Twitter) 발행 플레이북 (Claude in Chrome)

계정: Giwan. 280자 압축 + 세로 영상 첨부.

**선행 조건: YouTube 업로드가 먼저 끝나 watch URL이 있어야 한다.** X 카피엔 그 YouTube 홍보영상 링크가
반드시 들어간다(이 채널의 핵심 요구사항). 링크가 없으면(=YouTube 업로드 실패) X는 발행하지 말고
리포트에 "YT 링크 없어 보류"로 기록한다 — "링크가 생기면 X 발행" 원칙.

1. **계정 확인** — `navigate` x.com → 좌측 프로필이 Giwan 계정인지 확인. 아니면 건너뛰고 기록.
2. **작성창 열기** — "게시하기(Post)" 버튼 또는 홈 상단 작성 박스 클릭.
3. **본문 입력** — X용 카피(≤280자, 훅 + **YouTube 홍보영상 watch URL** + 해시태그 2~3개). YT 링크는
   필수, 280자가 빠듯하면 스토어 링크를 빼서라도 YT 링크를 남긴다. 길면 스레드로 쪼개되 1차는 단발 권장.
4. **영상 첨부** — 미디어 버튼 → 파일 input에 `file_upload`로 세로 영상 전달. 인코딩 막대가 끝날 때까지 대기.
5. **게시** — "게시하기" 클릭(영상 처리 완료 후 활성화됨).
6. **URL 캡처** — 프로필 타임라인의 새 게시물 → 게시물 URL(status/<id>) 확보.

영상 처리 전에는 게시 버튼이 비활성일 수 있다. 처리 완료를 확인하고 누른다.
