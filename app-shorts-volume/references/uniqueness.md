# 다계정 / 디지털 지문 밴 회피 규율 (Stage 3)

왜 이게 중요한가: 플랫폼은 로그인·쿠키 없이도 **수백 개 신호를 조합해 "같은 오퍼레이터"를 식별**한다(디지털 지문). 여러
계정에 유사 영상을 뿌리는 볼륨 전략은 바로 이 감지에 걸려, 하나가 밴되면 연결 계정이 **연쇄 섀도우밴**된다. 정량 임계값은
2026-07 딥리서치에서 신뢰할 근거를 확보하지 못했다(널리 도는 "10개 리포스트 → 추천 제외" 류 수치는 반증됨). 임계는
불명이지만 **감지 메커니즘 자체는 실재**하므로, 임계를 시험하지 말고 아래 규율로 리스크를 상시 낮춘다.

## 감지되는 4개 지문

1. **기기 지문** — GPU 렌더 시그니처, 설치 폰트, 화면 해상도, 센서 캘리브레이션, 배터리 방전 곡선, 오디오 지연.
   같은 폰/에뮬레이터로 여러 계정 = 동일 기기 지문.
2. **네트워크 지문** — IP·ISP·데이터센터/VPN 여부. 같은 와이파이/IP에서 여러 계정 = 즉시 연결.
3. **행동 지문** — 스크롤·세션 시각·액션 속도. 자동화(adb/uiautomator)의 기계적 리듬이 튄다.
4. **콘텐츠 지문(perceptual hash)** — 영상을 해시로 떠 "거의 같은 클립"을 감지. 살짝 트림/속도 변경으론 못 피한다.

## 규율

### 콘텐츠 (가장 통제 가능 — 여기부터)
- **계정·플랫폼별로 영상을 진짜 다르게.** 트림·워터마크 제거 수준 X. 훅·오프닝 프레임·자막·BGM·컷 순서를 재구성.
  Stage 1의 서로 다른 훅 변형을 계정별로 배분하면 자연히 유니크해진다.
- **플랫폼 워터마크 절대 금지.** TikTok 워터마크 영상을 Shorts/Reels에 올리면 추천 억제(공개 확인). 항상 클린 원본에서 각 플랫폼용으로 별도 익스포트.
- **캡션·해시태그·제목도 계정마다 다르게.** 동일 텍스트 복붙은 스팸 신호.

### 계정·기기·네트워크
- **계정당 기기 or 최소 IP 분리.** 한 기기로 다계정이 불가피하면 모바일 데이터로 IP를 로테이션.
- **신규 계정은 워밍 후 게시.** 개설 직후 대량 게시는 봇 신호. 며칠 사람처럼 소비(시청·좋아요)한 뒤 게시 시작.
  (참고: ig-android/ig-farming 기기 워밍 절차)
- **게시 리듬에 사람스러운 편차.** 정각 자동 게시·초 단위 규칙성 회피. 양·시각에 지터를 준다.

### 운영 원칙
- **임계를 시험하지 마라.** "몇 개까지 되나" 실험은 계정 자산을 태운다. 상시 유니크·상시 워밍이 싸다.
- **계정을 자산으로 취급.** 하나 키우는 비용이 크므로, 밴 리스크를 아껴 쓴다. 볼륨은 계정 수가 아니라 **영상 다양성**으로 낸다.
